# Feedback questions (draft)

To finalise after the check-ins.

## Week 1 check-in

1. How many days did you work with an agent with lineup on? Did anything stop you using it?
2. Did lineup flag something you wouldn't have noticed? What kind of change was it?
3. What was the most annoying thing so far?

## Week 2 check-in

1. Did you use `lineup rollback`? Did it put things back the way you expected?
2. Were there false flags? Did they make you ignore the HIGH lines?
3. Do you still read the end-of-reply line, or have you stopped noticing it?

## End-of-test form

**About you**
- Your role (for example backend developer, full-stack, student, team lead).
- What you mainly use coding agents for (for example new features, bug fixes, refactors, tests, scripts).
- Which agent you used: Claude Code, Codex, or both.
- Operating system: Windows, Mac or Linux.

**Usefulness**
- How often did lineup catch something you'd have missed? (never / once / a few times / often)
- Give one example, described in your own words (no code).
- Which command did you use most: `diff`, `risky`, `rollback`?
- Was the AI summary in `lineup diff` accurate? (1–5)

**Trust and noise**
- How many flags felt wrong? (none / a few / about half / most)
- Did you trust rollback with real work? Why or why not?
- Did the agent comment on lineup's output when you used `!`?

**Setup**
- How easy was install and `lineup init`? (1–5) What got in the way?

**Overall**
- Will you keep using lineup? (yes / maybe / no) Why?
- What one change would make it most useful?
- Paste your `lineup report` output here.
